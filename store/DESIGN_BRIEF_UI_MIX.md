# ТЗ: UI-микс Trade Master × стиль референса

Цель: освежить UI под аудиторию новичков в трейдинге + воронку **trial → Telegram**.  
Не копируем инфографик 1:1 — берём **структуру карточек**, оставляем **доверие и золото бренда**.

Превью-ориентиры: `store/assets/design_preview/`  
Референс-кадры: `store/assets/design_ref/`

---

## Формула

| Доля | Что |
|------|-----|
| ~70% | Текущий Trade Master: `#0B0D12`, золото `#D4AF37`, спокойный dark, Inter |
| ~30% | Референс: карточки с цветным акцентом, pill-теги, чёткая сетка модулей |

**Не делать:** сильный neon-glow, «6 одинаковых API-карточек» на весь экран, monospace-подкодовый вид, кислотный фиолетeverywhere.

---

## Что меняем (v1)

### 1. Тема (`lib/theme.dart`)
- Добавить палитру акцентов модулей (мягкие, не неоновые):
  - Lessons → зелёный
  - Practice / Chart → золото (бренд)
  - Community → Telegram blue `#229ED9`
  - Quizzes → мягкий фиолет (приглушённый текущий accent)
  - Journal / Path → коралл / циан (тихо)
- Хелпер карточки: `accentCard({Color accent})` — фон `card`, border 1px accent ~35–45% opacity, **без** outer glow / теней-неона.
- Радиус карточек ≈ 18–20 (как сейчас).

### 2. Home (`home_screen.dart`)
- **CommunityBanner** — первый сильный акцент (оставлю сверху), слегка в стиле accent-card (синяя кромка, pill «Telegram»).
- Блок прогресса / program day — в вид «accent card» (золотая кромка), не ломая структуру.
- Нижние быстрые действия / модули — **ряд или сетка 2×N** карточек с цветным акцентом + 1–2 pill-тега (напр. `trial`, `demo`, `live`).
- Не превращать Home в чистый 2×3 инфографик без CTA в чат.

### 3. Learning
- Карточки уроков / модулей: тонкая цветная обводка + badge `FREE` / locked как pill.
- Заголовки модулей можно чуть «инфографичнее» (uppercase / tracking), body — обычный readable sans.

### 4. Community / Premium-gate (galaxy)
- CTA «в Telegram» визуально в одном языке с новыми карточками (синий акцент), текст не менять радикально.

## Что не трогаем

- Логика: trial, entitlement, Galaxy `ENABLE_BILLING`, покупки play-сборки  
- Роутинг, сервисы, Supabase, IAP-код  
- Контент уроков / JSON  
- Сильный редизайн Trading chart / графиков (только оболочка экрана, если вообще)  
- Навигация (вкладки те же)  
- Логотип / имя Trade Master  
- Отдельная ветка «полностью VectorForge»  

---

## Приоритет экранов

1. **Home** + CommunityBanner  
2. **Learning** (список)  
3. Тема / общий виджет карточки  
4. Остальное — только если останется время  

---

## Критерий «готово»

- Новичок за 3 секунды видит: уроки / демо / **чат**  
- Не выглядит как крипто-скам или «айтишный TikTok-инфографик»  
- Galaxy-сборка без оплаты, community CTA на месте  
- Play-сборка с биллингом не сломана
