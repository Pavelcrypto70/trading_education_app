# Сиды для чата @academy_trading_club

**Языки постов:** English + Português (без русского — как договорились).  
**Русский ниже только для тебя** — подсказки «что это» и «куда вставить».  
**В Telegram копируй только блоки в \`\`\` … \`\`\`** (EN+PT). Русские пояснения в чат не кидай.

Сделай **до** раздачи APK. Цель: новичок зашёл — чат уже «живой».

---

## 1. Закреп (пин)

> **Что это:** приветствие + правила.  
> **Куда:** отправь сообщение → нажми на него → **Pin** / Закрепить.  
> **Зачем:** первое, что видят все новые участники.

```
👋 Trade Master — community

EN: Ask about lessons, homework, chart reviews, and trade talk here.

Rules:
1) No random “buy/sell” signals from strangers
2) No spam / shady bot links
3) Lesson questions are welcome

Free app: coming soon on Galaxy Store / APK
Full course + live discussion = this chat.

———

🇧🇷 Português: Tire dúvidas das aulas, tarefas, análises e converse sobre trading.

Regras:
1) Sem sinais de entrada/saída de desconhecidos
2) Sem spam ou links de bots duvidosos
3) Perguntas sobre as aulas são bem-vindas

App grátis: em breve na Galaxy Store / APK
Curso completo + discussões ao vivo = este chat.
```

## 2. Прогрев (5–6 сообщений за 1–2 дня)

> Копируй **по одному** посту с паузой (не всё подряд за минуту — выглядит как бот).  
> Отвечай сам себе лайками/комментариями, если чат ещё пустой.

### #1 — вопрос про вводные уроки

> **Что копировать:** блок ниже.  
> **Зачем:** вовлечь тех, кто уже начал trial.

```
EN: Who already finished intro lessons 1–2? One sentence: what helped you most?

🇧🇷 Quem já fez as aulas introdutórias 1–2? Em uma frase: o que foi mais útil?
```

### #2 — мини-разбор + вопрос

> **Что копировать:** блок ниже.  
> **Зачем:** показать, что в чате есть полезный контент, не только реклама.

```
EN — Today’s short note:
Before any entry, read structure first — not indicators.
Chat question: do you look at the full chart first, or jump straight to a lower TF?

🇧🇷 — Nota de hoje:
Antes de entrar, olhe a estrutura primeiro — não os indicadores.
Pergunta: você olha o gráfico inteiro primeiro ou já vai no TF menor?
```

### #3 — домашка (куда сдавать)

> **Что копировать:** блок ниже.  
> **Зачем:** направить людей в домашки / этот чат.

```
EN — Homework (text only, no screenshots):
“What I covered in the lesson and how I understood it in my own words”
→ post here or in @trade_master_homework

🇧🇷 — Tarefa (só texto, sem prints):
“O que eu vi na aula e como entendi com minhas palavras”
→ mande aqui ou em @trade_master_homework
```

### #4 — ошибка новичков (вовлечение)

> **Что копировать:** блок ниже.  
> **Зачем:** лёгкий отклик эмодзи — чат «оживает» без длинных ответов.

```
EN: Common beginner mistake: chasing the “perfect setup” instead of risk discipline.
Caught yourself doing that? Drop a ✊

🇧🇷: Erro comum de iniciante: caçar o “setup perfeito” em vez de disciplina de risco.
Já se pegou nisso? Manda um ✊
```

### #5 — опрос (стадии)

> **Что копировать:** блок ниже.  
> **Как:** в Telegram можно сделать как обычный текст **или** встроенный Poll с теми же вариантами.  
> **Зачем:** людям проще нажать реакцию, чем писать.

```
EN — Poll: where are you?
👍 just exploring
❤️ already reading lessons in the app
🔥 practicing on demo

🇧🇷 — Enquete: em que etapa você está?
👍 só explorando
❤️ já lendo as aulas no app
🔥 praticando no demo
```

### #6 — что делать после установки приложения

> **Что копировать:** блок ниже.  
> **Когда:** желательно прямо перед/после выдачи APK.  
> **Зачем:** объяснить путь: trial → вопрос в чат.

```
EN: Just installed the app? Start with the trial lessons, then write here:
“Finished lesson N — question: …”
That’s how this chat stays useful.

🇧🇷: Acabou de instalar o app? Comece pelas aulas grátis (trial) e escreva aqui:
“Terminei a aula N — dúvida: …”
Assim o chat fica vivo e útil.
```

## 3. Каждый день (минимум)

> **Не обязательно копировать шаблоны** — своими словами, но в том же духе:
> - 1 пост: вопрос / мини-разбор / опрос (**EN + PT**)
> - отвечать на каждое новое сообщение в тот же день

Этого хватает, чтобы фри-версия ощущалась живой.
